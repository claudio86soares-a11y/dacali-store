# DaCaLi Store — site profissional

Arquivos prontos para publicação no GitHub Pages.

## Publicação
1. Entre no repositório da DaCaLi Store.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Substitua os arquivos `index.html`, `produtos.html`, `estilo.css` e `script.js`.
4. Envie também todas as imagens `.jpg`, `.png` e `.webp`.
5. Aguarde a atualização do GitHub Pages e pressione Ctrl+F5 no navegador.

O catálogo inclui busca, filtros, botão direto para WhatsApp, layout responsivo e os novos produtos enviados.
